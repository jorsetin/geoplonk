# Bundled guessing-map data

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

Source files (downloaded 2026-10-15):
- https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_populated_places_simple.geojson

Geometry is unchanged. Properties were reduced to names, label positions/priorities and city coordinates. Maps and political boundaries reflect this dataset; it is a generalised world map, not a street map. Data is served only from the installed extension; there are no remote tiles, geocoding requests or prefetch jobs.
